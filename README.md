# Loom — Session 1 rehearsal / ensayo con SQLite

**Rehearsal package for the campus team.** Automated checks passed on macOS with Bun 1.4.0 using both SQLite and PostgreSQL. The independent facilitator dry run is pending. Complete that rehearsal before approving the participant release.

**Paquete de ensayo para el equipo del campus.** Las comprobaciones automáticas han pasado en macOS con Bun 1.4.0, tanto con SQLite como con PostgreSQL. El ensayo independiente del facilitador está pendiente. Completar ese ensayo antes de aprobar la entrega a los participantes.

To run Session 1 without containers or a PostgreSQL server, follow the [SQLite setup in English](QUICKSTART-SQLITE.md) or the [guía SQLite en español](QUICKSTART-SQLITE.es.md). Each member keeps their own local database.

Session 1 starts with three intentional TODO blocks and 13 expected failing tests. Read the [Spanish workshop](docs/course/session-01/WORKSHOP.es.md) or the [English workshop](docs/course/session-01/WORKSHOP.md).
